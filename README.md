# 🔒 CryptoSign

**Secure Digital Signature Tool for PDFs**

A powerful Python-based desktop application for digitally signing, verifying, and managing PDF documents with industry-standard cryptography.

![CryptoSign Banner](https://i.imgur.com/your-banner-image-link.png)

## ✨ Features

- **Digital Signature** – Create and apply secure signatures using cryptography
- **PDF Signing & Verification** – Sign and verify PDFs with pyHanko
- **Certificate Management** – Generate, import, and manage digital certificates
- **Batch Signing** – Sign multiple PDFs at once
- **Encryption & Decryption** – Secure your documents
- **Modern GUI** – Beautiful interface built with CustomTkinter
- **Admin & User Dashboard** – Role-based access
- **Audit Logging** – Complete history and tracking

## 🛠️ Tech Stack

- **Python** 
- **CustomTkinter** – Modern GUI
- **pyHanko + pypdf** – PDF signing engine
- **cryptography** – Core cryptographic operations
- **Pillow & ReportLab** – Image & PDF handling
- **SQLite** – Local database
